# Wish Snow Village (가칭)

눈 내리는 크리스마스 마을을 걸어 다니는 3D 힐링 웹게임. Three.js + Vite + TypeScript.

현재 단계: **Phase 1 — 3D 월드 및 캐릭터** (로컬 데모, 서버 연동 없음)

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. 배포용 빌드는 `npm run build` (결과물 `dist/`).

Node.js는 `~/.local/node` 에 설치되어 있습니다 (v22 LTS).

## 조작

| | PC | 모바일 |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 아래 조이스틱 |
| 시점 | 마우스 드래그, 휠로 확대 | 화면 드래그 |
| 상호작용 | E 또는 오른쪽 아래 버튼 | 오른쪽 아래 버튼 |

## 구조

```
src/
  main.ts                 부팅: 프로필 확인 → 게임 시작
  config.ts               월드 배치·구역·플레이어 수치
  core/
    Game.ts               렌더러·조명·루프·자동 품질 조절
    Input.ts              키보드 / 드래그 / 가상 조이스틱
    FollowCamera.ts       3인칭 카메라 (가림 처리 포함)
    quality.ts            기기별 품질 단계
  character/
    PlayerCharacter.ts    2등신 패딩 캐릭터 (GLB 교체 시 이 파일만 대체)
  world/
    World.ts              마을 조립, 충돌·가림·상호작용 대상 관리
    ChristmasTree.ts      중앙 소원 트리
    props.ts              마켓·오두막·가로등·벤치·표지판·선물
    foliage.ts            트리/소나무 가지·눈 지오메트리
    ground.ts             눈밭·언덕·광장·길·하늘
    Bulbs.ts              전구 (InstancedMesh + 글로우)
    Snowfall.ts           GPU 눈송이
  ui/                     HUD, 닉네임·패딩 색 팝업, 스타일
  data/profile.ts         닉네임 생성·검증, 로컬 프로필 저장
```

## 구현 상태

완료 (Phase 1)
- 중앙 광장, 거대 트리(오너먼트·전구·별·선물), 마켓 4곳, 가로등과 전구 줄, 벤치, 표지판
- 눈사람 들판, 눈싸움 놀이터(공간·눈벽만), 통나무 오두막 2채와 굴뚝 연기, 소나무 숲, 외곽 눈 언덕
- 2등신 패딩 캐릭터: 걷기·숨쉬기·눈 깜빡임, 이름표
- 가속/감속·회전 보간 이동, 장애물·월드 경계 충돌, 3인칭 카메라와 가림 처리
- 눈 내림, 전구 반짝임, 트리 반짝이기·마켓 구경·표지판 읽기 상호작용
- 첫 입장 닉네임(랜덤/다시 뽑기/글자 수·금칙어 검사) + 패딩 색 5종 선택, 프로필 변경
- 기기별 품질 단계와 프레임 저하 시 자동 해상도 조절

미구현 (다음 단계)
- Phase 2: 눈덩이 굴리기, 적설량, 눈사람 쌓기·꾸미기·녹기, 촬영·앨범
- Phase 3: 소원 작성·게시판·하루 1회 제한
- Phase 4: 눈덩이 던지기·피격 리액션
- Phase 5: Supabase 익명 인증과 실시간 동기화 — **현재 다른 접속자는 보이지 않으며 모든 데이터는 이 브라우저에만 저장됩니다**
- 발자국, 사운드, 나무 흔들림

## 확인 항목

- [ ] 첫 접속 시 닉네임 팝업이 뜨고, 색을 누르면 캐릭터 패딩 색이 바로 바뀐다
- [ ] 새로고침해도 닉네임과 색이 유지된다 (오른쪽 위 버튼으로 변경)
- [ ] 건물·나무·가로등·벤치를 통과하지 못하고, 맵 바깥 언덕으로 나갈 수 없다
- [ ] 트리나 오두막 뒤로 돌아가면 카메라가 앞으로 당겨진다
- [ ] 구역을 옮기면 위쪽에 구역 이름이 잠깐 표시된다
- [ ] 트리·마켓·표지판 근처에서만 오른쪽 아래 버튼이 나타난다
- [ ] 실제 휴대폰에서 조이스틱·드래그·프레임 속도 (에뮬레이션 화면만 확인됨)
